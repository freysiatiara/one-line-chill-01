## The entry

> My daughter's new drawing shows our family eating dinner, and I'm the one standing outside the window watching us eat.

One sentence, 118 characters. A mundane domestic detail — a child's drawing of family dinner — with one impossible wrongness: the narrator is outside the window, watching a family that includes him.

## How it works

`main.py` (Python standard library only) writes the line to the output file the grader reads: `ENTRY_OUTPUT`, else `OUTPUT_DIR` / `MAKEFUN_OUTPUT_DIR`, else `/output/entry.txt` when `/output` exists, otherwise `entry.txt` next to the script. It writes with plain `open`/`write` and sets mode `0644`.

Run it:

```sh
python3 main.py
```
